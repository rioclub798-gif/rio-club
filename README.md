# نادي ريو الإسكندرية - Rio Club Alexandria 🦅

الموقع الرسمي والصفحة التعريفية لنادي ريو الرياضي والاجتماعي بالإسكندرية (تقاطع امتداد شارع 45 ميامي مع الطريق الدولي الساحلي).

## 🌟 مميزات وعروض نادي ريو:
- **العضوية الأسرية الدائمة:** عضوية مدى الحياة وتورث للأبناء طبقاً للوائح النادي.
- **تسهيلات التقسيط:** تقسيط مباشر مع النادي حتى **60 شهراً** بدون فوائد بنكية معقدة.
- **دعوة زيارة مجانية (VIP):** يوم عائلي استكشافي كامل لجميع مرافق وملاعب النادي.
- **شبكة أتوبيسات خاصة:** خطوط نقل مكيفة تغطي أهم ميادين وأحياء الإسكندرية والمناطق المجاورة.

---

## ⚽ ألعابنا الرياضية (10 ألعاب معتمدة):
1. **كرة قدم:** ملاعب معتمدة وإضاءة ليلية وأكاديميات ناشئين.
2. **كرة سلة:** صالات وملاعب احترافية بمدربين معتمدين.
3. **سباحة:** مجمع حمامات سباحة أولمبية وترفيهية مغطاة ومكشوفة بأعلى معايير الأمان.
4. **تنس أرضي:** ملاعب ترابية وصلبة مضاءة ليلاً وتدريب لجميع المستويات.
5. **جمباز:** صالات أمان حركي متكاملة لتأسيس الأطفال والبطولات.
6. **جيم (Gym & Fitness):** أحدث أجهزة القوة والكارديو العالمية ومدربين شخصيين.
7. **كاراتيه:** كاتا وكوميتيه وتدريج أحزمة معتمد رسمياً.
8. **تايكوندو:** رياضة أولمبية وسرعة بديهة وبطولات جمهورية.
9. **كيك بوكس:** حرق دهون ولياقة بدنية ودفاع عن النفس.
10. **كونج فو:** أساليب وساندا وقتال حر بإشراف مدربي الاتحاد المصري.
